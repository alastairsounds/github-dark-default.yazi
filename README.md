# GitHub Dark Default

<img src="preview.png" width="600" alt="GitHub Dark Default Preview" />

## 🎨 Installation

```sh
ya pkg add alastairsounds/github-dark-default
```

## ⚙️ Usage

To set it as your dark flavor, change the content of your `~/.config/yazi/theme.toml` to:

```toml
[flavor]
dark = "github-dark-default"
```

See the [Yazi flavor documentation](https://yazi-rs.github.io/docs/flavors/overview) for more details.
